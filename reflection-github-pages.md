# Reflection: Publishing on GitHub Pages (STAR Method)

**Situation**  
The assessment required me to design a digital portfolio in Markdown, include my CV and mock interview video, and deploy the entire site using GitHub Pages so it is publicly accessible via a clean web link.

**Task**  
I needed to organise the portfolio files correctly in a GitHub repository, enable GitHub Pages, ensure all content (including reflections written in the STAR method) displayed properly, and reflect on the deployment experience.

**Action**  
I created a dedicated repository (or folder within my existing portfolio), added well-structured Markdown files with relative links, committed the changes, and enabled GitHub Pages from the main branch. I verified the live site on both desktop and mobile, fixed any broken links or formatting issues, and confirmed that the CV, video placeholder, and all STAR reflections were visible and professional. I also documented the repository structure for easy future updates.

**Result**  
The portfolio is now live on GitHub Pages with a shareable URL suitable for Blackboard submission and potential employers. Deploying via Pages gave me practical experience with static site hosting directly from a Git repository. It demonstrated how version control, Markdown, and free hosting can combine into a professional online presence — a key work-readiness skill. The process was straightforward once the file structure was correct, and I can now update the portfolio by simply pushing new commits.
