# Reflection: Coding My CV in Markdown (STAR Method)

**Situation**  
For the PRP370 digital portfolio assessment, I was required to create my professional CV entirely in Markdown and publish it as part of a GitHub Pages site that showcases work readiness training.

**Task**  
I needed to translate a traditional CV into clean, readable GitHub Flavoured Markdown while ensuring it looked professional when rendered on GitHub and GitHub Pages, and then reflect on the process using the STAR method.

**Action**  
I structured the CV with clear headings, bullet points, bold text, and links. I paid attention to GitHub Markdown features such as proper list formatting, horizontal rules, and consistent styling. I tested the rendering both in the GitHub preview and after deployment to Pages, making small adjustments to spacing and hierarchy until it was easy to scan. I also added a short note at the bottom confirming it was coded in Markdown for the assessment.

**Result**  
I successfully produced a professional, fully Markdown-based CV that renders cleanly on GitHub Pages. The process improved my understanding of lightweight markup for documentation and portfolios. It also reinforced how Markdown supports clear communication in developer workflows (READMEs, issues, pull requests). This artefact now serves as both evidence of technical skill and a living document I can update easily for future applications.
